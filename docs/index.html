Claude Code プラグイン

デザイナーの閃きを、
そのままコードに。

Airis（アイリス）は、デザイナーが Claude Code と対話しながらデザインをコードにするプラグイン。 Figma・手描きのラフ画・会話での要望のどれからでも、プロジェクトのルールに沿ったコード （Storybook・テスト込み）を生成し、開発リポジトリまで届けます。

はじめる GitHub で見る

インストールは Claude Code で 2 コマンドだけ。ターミナルでのダウンロード作業はありません。

/plugin marketplace add tu0607/airis-designer_cc_toolkit
/plugin install airis@airis

どのようなものからでもコード化可能

必要なのはこのプラグインと Claude Code だけ。Figma 無しでも全フローが完結します。

🎨Figma を使うメイン

既存の Figma デザインをそのままコード化。Variables/Styles はデザイントークンとして正しく引き継ぎます。

🖌️Claude Design を使う

claude.ai/design で作り込んだデザイン一式を受け取ってコード化。途中から確認・作り込みに使うのも OK。

✏️ラフ画を渡す

手描きスケッチの写真やスクリーンショットから「こんなのを作って」。

💬言葉で伝える

「こういう画面が欲しい」→ Claude がデザインを提案 → 合意してからコード化。

クイックスタート

前提は Git・Node.js v22+・Claude Code・GitHub CLI。Figma 接続は任意です。

  1. インストール

    Claude Code を起動して 2 コマンド。更新は /plugin marketplace update。

    /plugin marketplace add tu0607/airis-designer_cc_toolkit
/plugin install airis@airis

  2. セットアップ

    作業したいプロジェクトで実行。何度実行しても安全（冪等）、Figma はスキップ可。

    /airis:setup

  3. デザインをコード化

    あとは Claude が対話で進めます。要望や Figma URL も直接渡せます。

    /airis:build-code
# 例:
/airis:build-code ログイン画面を作りたい。メールとパスワードでログイン
/airis:build-code https://www.figma.com/...

  4. トークンだけ直した回は

    Figma で色・余白などを直しただけの回は、コードを作り直さず反映。

    /airis:build-token

勝手にやらない、が設計方針

Airis は候補を報告するだけ。判断はいつもあなたがします。

  • Push など外部に影響する操作は、必ず事前に確認します。
  • トークンの値を勝手に増やしたり、共通層に置いたりしません。
  • VRT 対象を勝手に増やしません。
  • Figma 側の設定不足を勝手に補完せず、不備として報告します。
